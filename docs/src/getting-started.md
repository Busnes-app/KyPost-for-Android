# Getting started

## Choose the intended installation

The Play, GitHub and F-Droid flavors have distinct package IDs and separate local data. Consult the current distribution status: a buildable flavor does not establish a live store listing. If several are installed, choose the intended copy when Android opens a `kypost://` link.

## Pair

Sign in to your server using an everyday mailbox account and generate a native-pairing QR code/link. Scan/open it in KyPost and confirm the server. Both server and registration URLs must be HTTPS and the registration URL must share the server origin.

Pairing completes only after server registration succeeds. Grant notification permission when requested, check the Inbox and test a send/reply. Key enrollment for client-custody encrypted mail is separate from relay pairing.
