# Everyday tasks

## Inbox and contacts

Use the server-provided keyword tabs and tune them in **Keywords**. Compose completes addresses from contacts; the address-book picker adds recipients directly. Open **Contacts** from the inbox menu to review two-way synchronization.

## Push or pull

The account's web Notifications page selects push or pull delivery. In pull mode the server does not send mail notifications through FCM; the app polls directly with its per-device credentials. Check notification permission on Android 13 or later.

## PGP and MFA

Use the PGP screen to show your public-key QR or scan another person's. A client-custody message decrypts locally only after this device has a sealed key envelope; otherwise it hands off to webmail. Approve only MFA challenges you initiated.

## Retire a phone

Revoke the individual device from the server's Security page. Before clearing or uninstalling an app, verify recovery access and distinguish its distribution channel from any other installed copy.
